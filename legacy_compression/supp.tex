\section*{S1. What the procedure does and does not select}
The algorithm selects a numerical representation for a declared empirical target. A representation comprises retained values and a decoder. Its possible chart encodings are not independent competitors when they retain the same values and share the same decoder. Means map to bars or mean dots; binned masses map to histograms or binned heatmaps; observations map to raw dots or a raw-data raincloud. A box uses minimum--maximum whiskers, not Tukey whiskers. Density reconstructions correspond to their declared finite grid and normalized cumulative interpolation, not an unspecified continuous idealization.

The earlier fifteen-family interface is retained only in the archived original implementation. Stacked bars, pie/donut charts, area charts and bubble plots need additional schemas. Paired lines and paired scatter plots expose within-person relationships not measured by a marginal target. Interval and forest displays retain uncertainty information that the current fidelity objective does not assess; assigning them a larger cost and declaring them inferior would answer the wrong question. The revised core consequently reports five representation classes, their configurations and explicit mappings to familiar displays.

A representation's error is not the error a reader makes. No scalar count measures attention, screen area or interpretation time. No numerical tie is broken by claiming perceptual superiority. The output includes the complete candidate table and error--size frontier. The optional single configuration used in simulations follows deterministic catalogue order if numerical objectives tie; the complete audit exports all tied configurations in \nolinkurl{optimal_sets.csv}.

\section*{S2. Elementary properties and scope counterexamples}
\textbf{Feasibility.} Retaining all observations reconstructs the empirical quantile functions exactly, hence $E_{\mathrm{raw}}=0$. The finite catalogue therefore has at least one qualifying representation for every nonnegative tolerance and accepted finite input.

\textbf{Monotonicity of minimum size.} If $\tau_1\leq\tau_2$, then $\{c:E_c\leq\tau_1\}\subseteq\{c:E_c\leq\tau_2\}$. Consequently $\min_{E_c\leq\tau_2}N_c\leq\min_{E_c\leq\tau_1}N_c$. A tolerance path can only move to the same or a smaller retained size as tolerance grows. The identity of the selected family need not have a monotone interpretation.

\textbf{Dominance.} A candidate with both larger error and no smaller cost than another candidate cannot improve the lexicographic optimum. Removing dominated candidates preserves the selection. This standard Pareto argument motivates displaying the frontier; it is not claimed as a new optimization theorem.

\textbf{Connection to the previous score.} The earlier qualifying score $1/(N_c+e_c/2)$, with $e_c=E_c/\tau\leq1$, induces the same ordering as lexicographically minimizing $(N_c,E_c)$ when integer counts are unchanged. Since $e_c/2\in[0,0.5]$, one extra scalar cannot be compensated by any permitted decrease in error. Reporting counts and errors separately exposes this preference. The revised catalogue and counts differ, so old and new recommendations need not agree.

\textbf{Sampling versus representation error.} The inequality $\|\widetilde\Delta_c-\Delta\|_\infty\leq E_c+\|\widehat\Delta-\Delta\|_\infty$ is the ordinary triangle inequality. It separates two error sources but provides no confidence coverage by itself. A bootstrap allowance is not substituted for the unknown sampling error as though a coverage theorem had been proved.

\textbf{Affine transformations.} In exact arithmetic, common positive affine transformations multiply contrast errors, pooled scale and bootstrap deviations by the same positive factor, preserving normalized errors when the decoder is transformed consistently. Common translations cancel. Finite-precision histogram boundary membership can violate this numerical property: the test suite records exceptions for 4 and 64 bins using an exactly spaced synthetic sample and its transformed version. A separate continuous random-sample test passes. The manuscript does not claim invariance at every floating-point boundary.

\textbf{Marginals are not individual changes.} For $x=(0,1,2,3)$ and $y=(3,2,1,0)$, marginal quantile functions are identical, so the contrast and its mean reconstruction are zero. Yet $y-x=(3,1,-1,-3)$. Preserving the marginal contrast does not preserve the paired-change distribution. Joint bootstrap indices respect paired sampling but do not change the target.

\textbf{Contrast preservation is not full-distribution preservation.} If both groups have the same complex distribution, their contrast can be zero and a mean representation can qualify. The method is not claiming to preserve their common multimodality. Similarly, the central target omits outer tails even though extreme observations may still affect means, ranges and interpolated summary decoders. A scientific question about those features requires a different objective.

\section*{S3. Numerical implementation and representation contracts}
The pooled scale is
\[
s^2=\frac{(n_x-1)s_x^2+(n_y-1)s_y^2}{n_x+n_y-2}.
\]
When within-group variance vanishes, the implementation uses $\max(\operatorname{range}(x\cup y),1)$. This convention is a computational fallback, not a scientifically meaningful scale; users should specify absolute resolution for constant or degenerate inputs. Independent missing values are removed within each group. Paired inputs are jointly filtered and must originally have equal lengths. At least four finite observations remain in each group. Pairing is never inferred from equal row counts.

Mean decoders use two values. Five-number decoders use ten values at ranks $(0,.25,.5,.75,1)$. Histogram configurations use $b\in\{4,8,16,32,64\}$ bins on a shared equal-width range and retain $2b+2$ scalars. Density configurations use $m\in\{8,16,32,64,128,256\}$ grid points per group and retain $2m+2$ scalars. Each group uses Scott's Gaussian kernel bandwidth. The shared support extends four times the larger bandwidth past both sample extrema, with an additional $0.01s$ lower bound for grid construction. Constant groups use a narrow Gaussian fallback. Density masses are trapezoidally integrated and normalized. Observations use $n_x+n_y$ scalars. There are 14 numerical configurations per comparison.

Counts exclude labels, units and common decoder conventions. Histogram mass vectors each sum to one, so their free-parameter count is two lower than the literal stored payload; this is explicitly tested as an alternative contract. Counts are neither minimum description lengths in bits nor measures of visual complexity. Deterministic auxiliary summaries computed from raw observations do not add stored payload under this convention.

Empirical inverse functions have knots at $i/(n-1)$. Five-number and inverse-density decoders are piecewise linear. Histogram inverse functions are piecewise linear with possible jumps at empty-bin probabilities. The union of knots, interval boundaries and adjacent floating-point values evaluates endpoint and one-sided maxima up to precision. The code cross-checks these errors against a dense-grid decoder evaluation. A feasibility slack of $10^{-8}$ relative to tolerance is used in configuration selection. Exact explanatory strata use the stated inequality without this slack; boundary cases should be inspected. Audit ties are exported at an absolute error tolerance of $10^{-10}$ for equal retained size.

\section*{S4. Audit design, convergence and sensitivity}
Input ordering is fixed by the bundled \texttt{data/derived/comparisons.json}. Case $i$, indexed from zero, uses seed $710000+i$ for default draws and $810000+i$ for the independent stream. The default uses 999 draws; the 99- and 499-draw checks use prefixes of those draws. Resampling is at the prepared participant or record unit, never at adjacent samples from a continuous physiological recording. The same default draws estimate tolerance and fixed-tolerance stratum agreement. Agreement below .80 is a provisional flag, not a confidence interval for a chart recommendation.

Probability intervals $[.01,.99]$ and $[.10,.90]$ rerun candidate errors and bootstrap deviations. Allowance percentiles .80, .90, .95 and .99 use the default draws. Fixed budgets .05, .1 and .2 times the observed pooled scale deliberately remove the bootstrap term. The displayed resolution path uses 40 logarithmically spaced fractions from .025 to 4. Cost tests hold errors and tolerance fixed: (i) add two mean markers to five-number cost; (ii) remove two constrained probability parameters from binned cost; (iii) set all costs equal. The equal-cost result is an ablation of compactness, not a plausible perceptual model.

Primary outcomes are descriptive counts. Features share participants and are not treated as independent studies. The audit was available during development; catalogue revision, sensitivity choices and simulation expansion were not preregistered. The revision is a new development analysis, not a prospectively frozen replication.

\section*{S5. Simulation distributions and endpoints}
Nine scenarios use independently drawn training and test arrays. Group-A sizes are $n\in\{20,80,320\}$; group B has size $n$, except the imbalance scenario with $4n$. There are 40 replicates per scenario and size, giving 1,080 pairs. The scenarios are:
\begin{enumerate}
\item Null: $X,Y\sim N(0,1)$.
\item Location: $X\sim N(0,1)$, $Y\sim N(.8,1)$.
\item Spread: $X\sim N(0,1)$, $Y\sim N(0,1.8^2)$.
\item Bimodal: $X\sim N(0,1)$, $Y=(.6Z+S)/\sqrt{1.8}$, where $Z\sim N(0,1)$ and $S=\pm1.2$ equiprobably.
\item Skew: $X=\exp(.6Z_1)$, $Y=\exp(Z_2)$ for independent standard normals.
\item Heavy tails: $X=T_1/\sqrt3$, $Y=1.5T_2/\sqrt3$, with independent Student $t_3$ variables.
\item Contamination: $X\sim N(0,1)$, $Y=Z+6I$, with $I\sim\mathrm{Bernoulli}(.05)$ independent of $Z\sim N(0,1)$.
\item Discrete: $X\sim\mathrm{Poisson}(2)$, $Y\sim\mathrm{Poisson}(3)$.
\item Imbalance: the spread scenario with group sizes $n$ and $4n$.
\end{enumerate}
For scenario index $j=0,\ldots,8$, group-A size $n$ and replicate $r=0,\ldots,39$, the data seed is $9300000+100000j+100n+r$. Training and test draws are consecutive independent draws from that generator. Bootstrap seeds are the data seed plus one and plus two, respectively; each uses 499 draws.

A selected configuration is refitted to test observations, including bin or grid range endpoints. Its representation class and bin/grid resolution remain fixed. All comparators are evaluated on the same test sample and target. Re-estimated tolerance uses the test allowance; frozen tolerance uses the training allowance. Fixed-budget selection uses $.2s_{\mathrm{population}}$ on training and test data, where $s_{\mathrm{population}}$ is the equal-mixture root-mean variance for balanced cases and the asymptotic 1:4-weighted root-mean variance for imbalance. This known population scale is a simulation device, not an estimated clinical margin.

Generating quantiles use analytic inverse functions where available and numerical inversion of Gaussian mixtures otherwise. Population errors are evaluated over 4,001 equally spaced probabilities between .05 and .95. This approximates the continuous supremum and may under-resolve jumps for discrete distributions; no exact population coverage claim is made. All sample sizes, scenarios, failures and raw per-case errors are included in CSV outputs. No human performance has been simulated. Bootstrap counts and scenario complexity were expanded after the original manuscript review.

\section*{S6. Provenance checks and primary exclusions}
The archived Parkinsons data contain 195 rows and 32 distinct prefixes obtained by removing the final recording suffix: 24 prefixes labelled Parkinson disease and eight labelled healthy. The source documentation describes 31 people, including 23 with Parkinson disease.\cite{parkinsons} The mismatch remains unresolved. The revised primary audit excludes all 22 associated feature comparisons; the full identifier audit and their exploratory results are retained. There is no evidence-based mapping that would justify merging two groups.

The CKD source CSV contains potassium values 39 and 47 at one-based data rows 62 and 129.\cite{kidney} These values are not parsing inventions. Their accuracy and units have not been resolved from source documentation. Primary arrays retain them. The separate omission analysis removes only these two observations from the CKD group, reducing its potassium sample size from 167 to 165; the comparison group remains 145. No rescaling or decimal correction is performed. The selected 32-bin representation becomes four bins, while both tolerances equal .6 and both detail strata require distribution information. This post hoc audit is not evidence that the omitted values are definitively erroneous.

Retinopathy remains a record-level demonstration because patient linkage is unavailable. HAR, BIDMC and wrist inputs are aggregated before resampling, as documented in the original preparation code. The large HAR source archive is not bundled; its prepared subject/activity medians and analysis arrays are included. Regeneration of the revised outputs uses those arrays, so it does not require a network download. Raw-download preparation is a distinct provenance workflow. No original source files are silently altered.

\section*{S7. Positive selection scores and exact ordering}
For a finite candidate discrepancy, define $S_c=100\max\{0,1-N_c/N_{\mathrm{raw}}\}$ when $E_c\leq\tau$ and zero otherwise. Here $N_{\mathrm{raw}}=n_x+n_y$. The implementation retains the existing $10^{-8}$ relative allowance for feasibility boundary comparisons. Nonfinite computations are marked unavailable. Qualification is reported separately: zero without a rejection mark means no eligible compression, whereas zero with a rejection mark means the candidate does not meet tolerance. Raw observations qualify exactly and score zero. Qualifying representations larger than the raw sample also receive zero; they cannot displace the raw baseline under the size tie-break.

For qualifying candidates with $N_c<N_{\mathrm{raw}}$, $S_c$ is strictly decreasing in $N_c$. Descending score followed by increasing discrepancy therefore implements the original lexicographic size--discrepancy selection. At zero, qualification precedes rejection; qualifying candidates are ordered by size and then discrepancy. Rejected candidates are ordered by discrepancy and then size, and unavailable candidates follow all finite candidates. If no candidate is smaller than the raw baseline and qualifying, this ordering still returns a minimum-size qualifying representation. Exact ties in size and discrepancy remain equivalent. Displayed scores are rounded to one decimal; comparisons use unrounded values. A rounded tie need not be an exact tie. Verification covers all 149 comparisons and boundary examples, including no eligible compression, equal-size candidates, infeasibility and unavailable computations.

There are no fitted weights and no new statistical threshold. The score reports the fraction of declared scalar payload removed subject to the existing tolerance. It does not count screen marks, estimate cognitive effort or measure statistical power. Because raw count is the denominator, the same retained size scores higher in a larger sample. Because qualification is a hard constraint, crossing the tolerance creates a discontinuity; the bootstrap, tolerance and size-contract sensitivity analyses remain necessary. Raw-dot zero is a compression reference, not evidence that a dot plot is visually inferior. All retained representations here are nonempty, so an exact score of 100 is not attained.

Main Figures 2 and 3 show the best setting of each eligible family at unique recommendation positions 1--7; the eight excluded families are documented in Table S3. Supplementary Figures S5/S6 expose the 14 shared numerical configurations, including discrepancy/tolerance, size and qualification. Equivalent encodings retain tied numerical results; a separate recommendation order uses fixed catalogue position only after score and discrepancy ties. This ordering does not modify the score or imply measured visual superiority. The complete family and setting outputs are \nolinkurl{all_149_cases_15_chart_families.csv} (2,235 rows) and \nolinkurl{all_149_cases_21_encoding_settings.csv} (3,129 rows), in \nolinkurl{revision/accessible_figures}. That directory also contains the 15 contracts, main-figure values and full numerical rankings. Four eight-point density computations are unavailable across the audit; all 84 illustrated numerical configurations are finite. The unchanged audit is \nolinkurl{revision/results/audit.csv}.
